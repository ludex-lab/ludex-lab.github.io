Personal Backup

A local utility for backing up selected folders on the owner's Mac to the owner's Google Drive, with encryption, version history and restoration.

This page explains a privately operated tool. There is no public signup, hosted backup service or access to the owner's files here.

What it does

  • Backs up folders selected by the owner, including changes since earlier backups.
  • Encrypts backup contents and file metadata locally before uploading them.
  • Keeps snapshots so the owner can restore a previous version into a separate local folder.
  • Runs on the owner's computer, with local scheduling and status records.

Why it uses Google Drive

Google Drive stores the encrypted backup repository in the owner's account. The tool requests drive.file to create and manage its own backup files and access files explicitly made available to it. It does not request unrestricted access to every file in Drive.

Google authorization connects the local tool to the owner's account. This informational website does not sign users in or receive backup contents, encryption keys or authorization tokens.

Privacy and control

The owner chooses the source folders and controls the backup schedule, retained snapshots, recovery key and Google authorization. Read the Personal Backup privacy policy for storage, retention and deletion details.

Operator and contact

Maintained by Ludex Lab for the account owner's personal use. For questions, contact the maintainers through the Ludex project. Do not post private files, credentials or recovery keys in public issues.

소유자의 Mac에서 선택한 폴더를 자신의 Google Drive에 암호화해 백업하고, 이전 버전을 복원하는 로컬 도구입니다.

개인적으로 운영하는 도구의 안내 페이지입니다. 공개 가입이나 온라인 백업 서비스, 소유자 파일에 접근하는 기능은 없습니다.

하는 일

  • 소유자가 선택한 폴더와 이후 변경 내용을 백업합니다.
  • 백업 내용과 파일 메타데이터를 로컬에서 암호화한 뒤 전송합니다.
  • 스냅샷을 보관해 이전 버전을 별도의 로컬 폴더로 복원할 수 있습니다.
  • 소유자의 컴퓨터에서 일정에 따라 실행하고 상태를 기록합니다.

Google Drive를 사용하는 이유

소유자 계정의 Google Drive에 암호화한 백업 저장소를 보관합니다. 요청 권한인 drive.file은 앱이 만든 백업 파일과 사용자가 명시적으로 허용한 파일을 관리하는 데 사용합니다. Drive의 모든 파일에 대한 무제한 접근 권한을 요청하지 않습니다.

Google 인증은 로컬 도구와 소유자의 계정을 연결합니다. 이 안내 웹사이트에는 로그인 기능이 없으며 백업 내용, 암호화 키, 인증 토큰을 받지 않습니다.

개인정보와 제어

소유자가 대상 폴더, 백업 일정, 스냅샷 보관, 복구 키와 Google 접근 승인을 관리합니다. 저장·보관·삭제 방법은 Personal Backup 개인정보처리방침에서 확인할 수 있습니다.
