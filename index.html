From individual organs to collective organs

Prompt engineering optimized one call. Context engineering optimized the shell around one agent. We began by growing individual organs — memory, emotion, immunity, senses — onto that shell. Then we measured both sides. As native CLI harnesses matured (Claude Code, Codex, Antigravity, Cursor, Grok), single-agent harnesses absorbed tools, memory, and planning on their own, and our pre-registered cells showed no detectable edge for runtime individual organs. What no single vendor harness can build, however, is the village-level body shared across heterogeneous model tribes: collective memory that resists monoculture, collective immunity against cross-tribe contamination and uncalibrated judges, and shared homeostasis. So Ludex moved one scale up — treating each native harness as a capable cell, and engineering the collective organs of a superorganism. Retraction, 2026-08-31: an earlier version claimed individual organs as the rung above context engineering. Native harnesses made that an unmeasured claim; a three-lab review retired it pending same-model evidence. Every record, including the ones that did not flatter us, remains public.

Shared village-level collective organs

Forged under real operational load in our prototype village and designed to be shared across villages — an open architecture where new organs can be added as societies evolve.

Collective Memory

Shared memory & dreaming without monoculture

Dual-pool shared ledgers (exploitation + exploration), Copy-on-Write offline dreaming, per-tribe and temporal-bucket occupancy caps so short bursts or one dominant tribe never erase quieter facts.

Collective Immunity

Cross-tribe audit, quarantine & verifier checks

Independent cross-tribe landing audits, retraction contamination lineage, deterministic rule-audits ("verify the verifier"), exact-fraction evidence binding, and outbound leak gates.

Collective Homeostasis

Multi-pool metabolism & stall resilience

Quota and cadence balancing across heterogeneous CLI tribes, state-aware live steering that cuts silent zombie stalls without killing legitimate long runs, and host-level load governors.

Collective Calibration

Judge debiasing & fingerprinted chronicles

Round-robin reviewer rotation and sealed calibration probes that separate real capability gaps from reviewer strictness, alongside Git-blob-fingerprinted chronicles that replace hand-memory summaries.

Collective Evolution

Self-evolving harness governance

Four-axis tracking (Selection · Activation · Attribution · Generalization) so landed switches earn their keep or retire, plus memory-hygiene benchmarks and failure-to-skill lifecycles.

Open Architecture

Extensible as new villages differentiate

The organ list is never frozen. Each village inherits the shared platform core and grows specialized organs — creative, clinical, or scientific — according to the environment it inhabits.

One substrate, many superorganisms

Ludex is not a single rigid template. Naru acts as the prototype lab where common collective organs are forged and stress-tested; once shared on the platform, other villages differentiate into entirely different superorganisms.

Quick start

Requires Python 3.10+. No API key needed for CLI-auth or local (Ollama) brains.
